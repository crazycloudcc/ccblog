# crazycloudcc's blog

Personal blog by crazycloudcc — notes on software, cloud infrastructure, and everyday engineering.

Built with [Next.js](https://nextjs.org) and [Tailwind CSS v4](https://tailwindcss.com).

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Pages

- `/` — Home
- `/blog` — Post list
- `/blog/[slug]` — Post detail
- `/about` — About & contact
