Welcome to your new blog.

This is a sample post living under `content/notes/`. Edit it, delete it, or write your own - the filename becomes the URL (`/blog/hello-world`).

![A calm desk with a terminal open](https://images.unsplash.com/photo-1517694712202-14dd9538aa97?w=1200&h=630&fit=crop)

## What you can write

- Headings, **bold**, _italic_, and `inline code`
- [Links](/blog) and images
- Fenced code blocks with copy buttons:

```bash
npm run dev
```

- Inline video via `::video[Caption](url)`:

::video[Demo clip](https://interactive-examples.mdn.mozilla.net/media/cc0-videos/flower.mp4)
