## v1.0.0 — First public release

First public release of **ccblog** — a forkable terminal-themed personal blog and web lab built with Next.js 16.

### Site & terminal UI

- macOS-style terminal shell with title bar (live clock, timezone, session geo), nav, and status bar
- Dynamic `cwd` in title bar and nav that follows the current route
- Light / dark / system theme with flash-free `theme-init` and persistent preference
- CRT desk atmosphere: grid drift, scanlines, vignette (`prefers-reduced-motion` respected)
- Unified page entry on subpages with fade-in
- Terminal-style 404 page

### Blog

- Markdown posts from `content/notes/` with gray-matter frontmatter
- Post list with year groups, reading time, tags, tag filter
- Pagefind search, prev/next, related posts, JSON-LD, OG images
- RSS (`/feed.xml`), sitemap, robots

### Playground (`/playground`)

- In-browser C11 / C++17 compile & run via browsercc WASM
- Monaco editor, stdin, examples, share links, local draft persistence

### Content blocks

- Interactive post directives: `:::trace`, `:::bench`, `:::annotate`, `:::playground`, and related blocks

### Apps (`/apps`)

- Optional App Store catalog synced from iTunes Lookup API at build time

### Tooling

- Next.js 16 App Router, React 19, Tailwind CSS v4, TypeScript
- `npm run build`: apps sync → static build → Pagefind index
- GitHub Actions: lint + build on push/PR

### Requirements

- Node.js 20+
- `NEXT_PUBLIC_SITE_URL` for production metadata
- Optional `APPLE_DEVELOPER_ID` for `/apps` sync
