# 图解实验室栏目规范

## 定位与路由

- `/learn` 与 Notes (`/blog`) 并列：图形、交互、反例用于理解规律；笔记保留推导和代码，不删除原文
- 单篇实验使用 `/learn/<slug>`，标题、描述、canonical、站点地图和内部链接统一到此路径
- 2026-10-07 迁移二分查找和 LIS。旧 `/blog/binary-search/visual`、`/blog/longest-increasing-subsequence/visual` 由 Next 配置在文件系统路由之前返回 HTTP 308，查询参数透传。只迁移已知页面，不将任意未知 slug 重定向
- 实验与相关 Notes 双向链接；实验导航可返回栏目首页

## 内容与展示

- 首页只展示已存在的实验与实际分类；分类由实际已实现的课程驱动。不为计划中的内容制造空分类、假文章或完成数量
- 新实验资料包含：分类、难度、前置知识、预计学习时长（明确为估计）、学习目标、不变量、例子、反例、自测
- 首页预览图必须表达该实验的实际概念；图像提供文本替代，导航支持键盘，窄屏不依赖横向滚动
- 二分现有满幅双轨 SVG、算法和播放性能保持不变；LIS 此次仅迁移入口与导航，不代表视觉重做
- 时长包含阅读、尝试和自测，不能宣称已测得的完成时间

## 记账与验证

- 迁移或重做不算新日更；实际发布写入 `article-publication-log.md`
- 尚未批准的七日候选不因栏目建立而自动获准
- 发布前核对远端并发，完成 tests、lint、类型检查、构建和独立审查；检查旧 URL 状态码、查询参数、原文和未知 URL 的路由行为
- 仅走 Git 自动部署：精确 preview 提交的 CI 和部署成功后才推进 main，随后只读核验生产 CI、Ready 与域名绑定
- 如无法做真实浏览器或手机验收，应如实记录；源码/自动化检查不能替代真实画面验收

## 搜索与 AI 阅读制作规范（2026-10-07）

- 图形是首屏主舞台；图下的答案、适用条件、逐步例子、复杂度和常见误区必须在服务端输出，不以播放、展开或脚本运行作为阅读前提
- 标题写完整知识名，再给缩写；Learn 解释状态和反例，Notes 保留深入推导、边界与可运行代码，避免两页变成复制全文
- `lib/visualizations/lessons.ts` 是课程事实与实际发布日期、更新时间的单一来源；页面、Article/BreadcrumbList、sitemap 和 Markdown 从这里生成，不用构建时间冒充内容更新
- 署名沿用仓库站点作者，不虚构经历、资历或外部背书；每课提供可核实的算法/标准参考
- 每课独立 OG 图展示真实过程，原生 SVG 和 PNG 由 `node scripts/generate-lesson-og.mjs` 生成；修改示例后同步重建并检查图示与轨迹
- `/learn/<slug>/index.md` 与 `/llms.txt` 只是阅读便利入口，不承诺排名、收录、训练权限或 AI 引用；引用指向 `/learn/<slug>` canonical
- 自动化测试覆盖空数组、重复值、单元素、未命中、严格递增/非下降和 tails 不一定是子序列；区分算法复杂度与保存可视化快照的开销
- SEO/GEO 补充、栏目迁移与重做均不算新文章；候选计划本身不授权启动。2026-10-09 的今日新篇另获明确启动授权，其余候选仍待审。
- 独立几何文章直接归入 Learn；无既有 Notes 时，不制造无效 Notes 链接。已有二分 / LIS 双向入口与旧 308 保留。
